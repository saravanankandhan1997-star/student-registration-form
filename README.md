Student Registration Form 💙
About the Project
The Student Registration Form is a beginner-friendly web development project created using HTML, CSS, and JavaScript. It provides a simple interface for entering student details and displaying registered students in a table.
The project features a clean blue and beige theme, stylish fonts, and a responsive layout.
Features
Student registration form
Input fields with basic form validation
Gender and course selection
Success popup after registration
Registered students list in a table
Total registered students count
Delete registered student details
Reset form functionality
Duplicate email validation
Browser local storage to retain registered details
Responsive design for mobile and desktop screens
Technologies Used
HTML5 – Structure of the webpage
CSS3 – Styling, layout, colors, and shadows
JavaScript – Form functionality and student management
Local Storage – Saving student records in the browser

How to Run the Project
Clone or download this repository.
Open the project folder in Visual Studio Code.
Open index.html using Live Server.
Enter the student details in the form.
Click Register to add a student.
View registered students in the table below.
